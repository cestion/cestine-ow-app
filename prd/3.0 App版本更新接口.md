# 3.0 App 版本更新 — 客户端接口说明

> 产品需求见 `PRD_V3.0_App版本更新管理.docx`。  
> **dev 实测**（2026-09-02）已对齐下方契约。  
> **客户端实现**：见 `todo/prd-v3-app-version-update.md`（Step 1–8 已完成）。  
> **Swagger**：远程 `v3/api-docs`（13001–13007）**尚未**收录本 path；本地 OpenAPI 见 `web-onestory-www/api-admin.yaml`。

## 检查更新

| 项 | 值 |
|---|---|
| **Method** | `GET` |
| **Path** | `/api/admin/v1/app-version-updates/check` |
| **Base URL** | 与全局配置相同，如 `https://dev-api-gateway.actqa.com` |
| **鉴权** | 无（静默检查，失败不阻断进 App） |

### Query 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `channel` | 是 | `ios` / `android` / `apk`（Google Play 用 `android`） |
| `version_name` | 是 | 当前 App 版本号，如 `1.1.0`（`PackageInfo.version`） |

### 示例

```bash
# iOS
curl "https://dev-api-gateway.actqa.com/api/admin/v1/app-version-updates/check?channel=ios&version_name=1.3.1"

# 官网独立 APK
curl "https://dev-api-gateway.actqa.com/api/admin/v1/app-version-updates/check?channel=apk&version_name=1.3.1"
```

### Response — 需要更新

```json
{
  "code": 200,
  "msg": "Success",
  "data": {
    "need_update": true,
    "type": "Remind",
    "version_name": "1.3.2",
    "download_url": "https://static.actqa.com/apk/storyfun.apk",
    "contents": {
      "zh": "中文",
      "en": "英文",
      "ja": "日语",
      "es": "西班牙",
      "vi": "越南",
      "tr": "土耳其"
    }
  },
  "meta": null
}
```

### Response — 已是最新 / 无需更新

当 `version_name` ≥ 目标版本，或该渠道未配置更新时，仅返回最小字段：

```json
{
  "code": 200,
  "msg": "Success",
  "data": {
    "need_update": false
  },
  "meta": null
}
```

### `data` 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `need_update` | boolean | **客户端弹窗唯一开关**：`true` 必弹，`false` 不弹 |
| `type` | string | `Remind` / `Force` / `Click`（大小写不敏感）；无法识别时客户端按 `Remind` 兜底 |
| `version_name` | string | **目标版本号**（非当前版本）；可空，弹窗仍展示 |
| `download_url` | string | 跳转链接（App Store / Play / APK）；可空，点「立即更新」不跳转但仍弹窗 |
| `contents` | object | 多语言公告，`zh/en/ja/es/vi/tr`；可空，弹窗仍展示、公告区为空 |

### 渠道映射（App 侧）

| 运行环境 | `channel` | 客户端如何决定 |
|----------|-----------|----------------|
| iOS App Store | `ios` | `Platform.isIOS` |
| Android Google Play | `android` | Android 默认 |
| 官网 / 独立 APK | `apk` | 打包时 `--dart-define=DISTRIBUTION_CHANNEL=apk` |

非法 channel 返回 `400`：`channel 仅支持 ios/android/apk`。

> **注意：** CI `build-story-apk.yml` 已注入 `--dart-define=DISTRIBUTION_CHANNEL=apk`，官网 APK 检查走 `channel=apk`。本地 `flutter run` / 未加 define 的 Android 包仍默认 `android`。

### 与 PRD 字段对照

| PRD / 原草案 | 实际 API |
|--------------|----------|
| `needUpdate` | `need_update` |
| `updateType` / `REMIND` | `type` / `Remind` |
| `targetVersion` | `version_name` |
| `storeUrl` | `download_url` |
| `description`（单字符串） | `contents`（多语言 map） |

### 客户端调用时机

1. **冷启动**：`MainShell` 首帧；先处理 pending deletion gate，再 `checkOnLaunch()`  
2. **热启动**：回前台；距上次检查 ≥ 1 小时才重新请求；**Force** 在 1h 内用本地 pending 快照必弹  
3. **设置 → 版本**：主动点击；最新 Toast；有更新弹窗；失败 Toast「版本检查失败，请稍后再试」

### 弹窗频次（客户端本地）

| type | 行为 |
|------|------|
| `Force` | 每次冷启动 / 回前台必弹，不可关闭；请求失败时用缓存 pending 兜底 |
| `Remind` | 同一 `version_name` UTC 自然日最多 1 次；点「以后再说」当日不再弹；目标版本变更立即再弹 |
| `Click` | 仅设置页主动检查时弹窗 |

### 容错（客户端实现）

| 场景 | 行为 |
|------|------|
| 冷/热启动请求超时或失败 | **静默**，不阻断进 App |
| 设置页主动检查失败 | **Toast** 提示失败 |
| `need_update=false` | 不弹窗 |
| `need_update=true`，但 `contents` / `download_url` / `version_name` / `type` 缺失 | **仍弹窗**；`type` 未知按 Remind |
| pending deletion + Force | 先进入删除页，Force 用根 Navigator 盖在上面 |
| pending deletion + Remind | 到删除页后不弹提醒更新 |

### 公告语言

- 按 **App 内语言设置**（`appLocaleProvider` / 设置 → 语言）取 `contents`  
- 缺省回退：`en` → `zh`  
- **不**使用手机系统语言
